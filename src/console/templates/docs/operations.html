Each trading morning

  1. Run the Upstox login: python -m src.broker.auth.
  2. Start the scanner (python -m src.main) and, if you use it, the movement service.
  3. Open the console's System health page: the token, broker API, market data and scanner heartbeat should be OK by 09:20.
  4. Check Risk & safety: kill switch released, limits as expected, event calendar populated for the coming days.
  5. Only if you intend to trade live today: arm in a terminal with python -m src.execution.live_gate --arm.

During the session

  • The status bar refreshes every 20 seconds. A stale scanner, an engaged kill switch or an armed gate is always visible there.
  • If anything looks wrong, engage the kill switch first and investigate second.

After the close

  • Review the day on Performance and Trade blotter; download the CSV for your records.
  • Compare live fills against the broker's contract note.
  • Disarm happens automatically at midnight; disarm earlier from the Risk page if you are done.

Weekly

  • Verify the audit chain. Back up data/ (it holds all trade history and the console database).
  • Re-run backtests after any settings change, and judge changes on out-of-sample results.
