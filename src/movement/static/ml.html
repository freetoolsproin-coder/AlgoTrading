Train a model

Logistic regression on completed bars, chronological split: the latest days are never used in training and give the test numbers. The threshold is set on the end of the training period, and the strategy gives no signal on any day the model trained on. A good AUC is not a profitable options strategy: backtest it with option costs (python -m src.movement.backtest --strategies ml_signal).
