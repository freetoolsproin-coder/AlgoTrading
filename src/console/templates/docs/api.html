Signed-in sessions can read JSON from these endpoints (same cookie as the pages; there are no write endpoints):

  • GET /api/status: the status bar (scanner heartbeat, market session, live gate, kill switch).
  • GET /api/summary: headline metrics per source, kept separate.
  • GET /api/performance?source=paper&book=scanner-v1&from=2026-10-01&to=2026-10-31: full metrics for a selection.
  • GET /api/risk: today's risk state per lane, kill switch and live gate.
  • GET /api/broker: the read-only broker snapshot.
  • GET /api/health: every health check.
  • GET /healthz: unauthenticated liveness probe; returns only {"status": "ok"}.

Downloads: /reports/trades.csv, /reports/trades.json (same filters), /reports/orders.csv, /reports/audit.csv (admin).
