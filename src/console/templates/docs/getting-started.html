The console is a web interface over the trading application in this folder. It shows real results and system state; the trading itself still happens in the scanner and the movement service.

What runs where

  • python -m src.main: the NIFTY / SENSEX scanner, its three paper books (v1, v2, v3), the order engine and the built-in dashboard on port 8502.
  • python -m src.movement: the movement-trigger service and its paper books, on port 8503.
  • python -m src.console: this console, on port 8510. It reads the other two; it does not need them running.

First run

  1. Install the requirements once: python -m pip install -r requirements.txt.
  2. Create the first admin in a terminal: python -m src.console --create-admin (add --username yourname for another name).
  3. Start it: python -m src.console, or in VS Code pick Trading console (web) and press F5.
  4. Open http://127.0.0.1:8510, sign in and accept the risk disclosure.
  5. Under Account, turn on two-factor sign-in.
  6. Under Credentials, move your API keys out of plain-text .env into the encrypted vault.

Settings

Optional, in [CONSOLE] of config/scanner.ini: host, port, session_minutes, secure_cookies, max_login_failures, lockout_minutes, broker_cache_seconds, require_2fa_for_admin. Restart the console after changing them.
